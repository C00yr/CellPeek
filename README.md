# CellPeek

CellPeek 是一款面向飞书 / Lark 电子表格的 Chrome 扩展。点击表格单元格，即可在浏览器侧栏中舒适地查看、搜索、复制和编辑内容，尤其适合长文本、Markdown 与 JSON 数据。

## 产品亮点

- **专注阅读**：把单元格内容放到独立侧栏，长文本无需挤在表格里阅读。
- **多种展示方式**：支持 Markdown、JSON 结构视图、数学公式和原文显示。
- **分栏对比**：支持单栏、左右分栏和上下分栏，可同时查看并锁定不同单元格。
- **快速查找与复制**：在当前内容中搜索、高亮和切换结果，也可复制全文或单独复制 JSON 成员。
- **便捷定位**：点击侧栏顶部的单元格地址，即可返回来源标签页和工作表并定位到该单元格。
- **安全编辑**：可在侧栏中修改内容并写回原单元格；无法确认目标时会保留草稿，避免误写。
- **本地处理**：内容展示、搜索和写回均在浏览器本地完成，不会上传到第三方服务器。

## 安装

1. 下载并解压本仓库。
2. 在 Chrome 中打开 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目文件夹。
5. 打开或刷新飞书 / Lark 电子表格，点击浏览器工具栏中的 CellPeek 图标。

## 基本使用

1. 在飞书 / Lark 表格中点击一个单元格，内容会自动显示在侧栏。
2. 按需切换 `自动`、`MD`、`JSON` 或 `原文` 展示模式。
3. 使用顶部按钮进行分栏、搜索、复制、锁定或编辑。
4. 编辑完成后点击“完成”，CellPeek 会定位来源单元格并验证写回结果。

## 支持范围

CellPeek 支持飞书和 Lark 网页版电子表格，包括 `feishu.cn`、`larksuite.com` 和 `larkoffice.com` 相关域名。建议使用当前稳定版 Chrome。

部分租户或页面版本可能存在界面差异。当 CellPeek 无法可靠确认目标单元格时，会优先保护数据，不执行猜测写回。
