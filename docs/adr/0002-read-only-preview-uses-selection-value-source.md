# 只读预览只接受当前选区值源

CellPeek 对普通和受保护单元格都优先读取飞书为当前选区提供的完整值源，并独立使用可编辑编辑器判断能否键入。编辑器的存在不得改变内容来源；只有当前选区值源不存在时才回退读取编辑器。值源存在但没有内容时，结果就是空单元格；不得使用上一格内容或页面候选文本替代当前值。

这一选择让内容读取与编辑权限互不干扰：有内容就展示原内容，空值就展示空白，可编辑性只控制键入入口。代价是飞书调整值源结构时需要更新对应的平台适配器，但结构失配不能成为恢复页面猜测逻辑的理由。

读取由用户选中、键盘导航、侧栏首次打开、标签页切换或解除锁定等事件触发。单次读取可以为等待飞书值源同步进行有限次重试，但不得建立常驻定时轮询，也不得通过合并上一格状态来补偿轮询结果。
