# 键入只写回可信定位的原逻辑单元格

CellPeek 将来源浏览器标签页、来源工作表、原地址、原内容和邻近单元格特征保存为写回目标快照；完成键入时先返回来源页面并重新定位、验证目标。回到来源工作表后，原地址与原内容均一致即可写回，不要求容易受虚拟化渲染影响的邻近特征一致；只有原地址不再匹配、需要追踪发生位置变化的原逻辑单元格时，才使用邻近特征判定。重新定位后优先用已准备的系统剪贴板向飞书当前 Canvas 选区发送原生粘贴命令，失败时再发送带数据的合成粘贴事件；清空内容则发送删除事件，并统一通过公式栏读取结果。不得直接修改公式栏 DOM，也不得再次点击推测出的屏幕像素坐标。表格结构变化、当前选区无法确认或提交结果无法验证时，均保留草稿并进入等待重新定位。提高表面成功率不值得承担静默误写其他单元格的风险。

首次进入工作表、解除锁定刷新或用户选择后，侧栏成功展示且具有明确来源与地址的单元格快照，均可成为当前展示单元格并直接进入键入；键入开始时冻结该可见快照，刷新中的未展示选区不得替换它。空单元格只有在地址与空值均连续稳定时才建立快照。写回验证以来源文件、来源工作表、明确地址和公式内容为主要证据；Canvas 虚拟化产生的活动单元格 DOM 或屏幕坐标只作辅助，不得否决已经稳定一致的主要证据。
